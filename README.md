# OmniFood Responsive Landing Page

A beginner-level responsive food delivery landing page built using only HTML and CSS.

## Sections
1. Header and hero banner
2. How it works (three steps)
3. Our cities (four cards)
4. Customer testimonials (three reviews)
5. Pricing plans (three cards)
6. Footer with links, social icons, and copyright

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout

## How to run
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a browser, or use Live Server in VS Code.
3. An internet connection is needed for the external images.

## Responsive layout
- Desktop: default styles
- Tablet: `@media (max-width: 834px)`
- Mobile: `@media (max-width: 390px)`
- Small mobile support: `@media (max-width: 320px)`

## Notes
This is a front-end educational demo. The links are section links/placeholders and there is no ordering or payment functionality.
